
JunoPy
======

**JunoPy** is a Python package that can be used to download and analyze plasma
and fields data from the Juno spacecraft which is stored on the Planetary
Plasma Interactions (`PPI <https://pds-ppi.igpp.ucla.edu/>`_) node of NASA's 
Planetary Data System. Currently, it can be used to analyze data from the
following instruments - 

    1. Magnetometer
    2. Waves 
    3. JEDI Energetic Particle Detector
